Flowmail

SaaS · AI

Asystent AI i CRM dla doradców sprzedaży. Z krótkiej notatki (także głosowej) generuje spersonalizowany mail w ~30 sekund — na podstawie historii klienta i bazy 3 700+ materiałów branżowych. Drugi model AI weryfikuje treść, doradca zatwierdza i wysyła ze swojego adresu.

  • ✓ RAG na bazie wiedzy + generowanie i weryfikacja przez Claude
  • ✓ Baza klientów, zaplanowane wysyłki, newslettery, kalendarz
  • ✓ Notatki głosowe (Whisper), skrzynka Messenger, posty FB z AI
  • ✓ Model SaaS z planami i limitami dla wielu doradców

Gratka Alerts

SaaS

Wielodostępowy system monitorowania ofert nieruchomości. Użytkownik ustawia kryteria (lokalizacja, cena, metraż, balkon, garaż, piwnica), a system co godzinę skanuje Gratka.pl, deduplikuje oferty i wysyła powiadomienia email o nowych pasujących ogłoszeniach.

  • ✓ Scraper w n8n uruchamiany co godzinę
  • ✓ Izolacja danych między użytkownikami
  • ✓ 7-dniowy trial i plany subskrypcyjne
Django PostgreSQL n8n Celery HTMX Tailwind CSS

sprzedajm.pl

Lejek sprzedażowy

Jednostronicowy lejek generujący leady dla N Inwestycje — łódzkiej firmy skupującej nieruchomości za gotówkę i prowadzącej pośrednictwo. Każda sekcja, od problemu sprzedającego po FAQ, prowadzi do 3-krokowego quizu wyceny, a zgłoszenie trafia mailem do handlowca razem z informacją, którą ścieżkę wybrał klient.

  • ✓ Routing intencji: osobne ścieżki „skup” i „pośrednictwo”
  • ✓ Quiz wyceny z walidacją telefonu i obsługą leadów w PHP
  • ✓ SEO i widoczność w AI: dane strukturalne JSON-LD, robots.txt dla botów AI
  • ✓ Agent AI (Claude API) generujący miesięczny plan postów na FB i IG
HTML / CSS / JS PHP Python Claude API JSON-LD
